## PostgreSQL

### Daily Commands
sudo service postgresql start
sudo service postgresql status
psql "postgres://postgres:postgres@localhost:5432/gator"  # connect to gator db
\dt                                                        # list tables
\q                                                         # exit psql

### First Time Setup (already done)
sudo passwd postgres                     # set system user password to 'postgres'
sudo -u postgres psql                    # enter psql shell
CREATE DATABASE gator;                   # create the database
\c gator                                 # connect to it
ALTER USER postgres PASSWORD 'postgres'; # set database user password

### Note
Two different passwords:
- System user: sudo passwd postgres
- Database user: ALTER USER postgres PASSWORD 'postgres'
'psql gator' only works on Mac — always use the full connection string on Linux/WSL

### Connection Strings
Goose:      postgres://postgres:postgres@localhost:5432/gator
App/Config: postgres://postgres:postgres@localhost:5432/gator?sslmode=disable
Format:     protocol://username:password@host:port/database

## Goose Migrations

### Install
go install github.com/pressly/goose/v3/cmd/goose@latest

### Usage (run from sql/schema directory)
cd sql/schema
goose postgres "postgres://postgres:postgres@localhost:5432/gator" up
goose postgres "postgres://postgres:postgres@localhost:5432/gator" down

### Migration File Format
-- +goose Up
CREATE TABLE ...

-- +goose Down
DROP TABLE ...;

## SQLC

### Install
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest

### Usage (run from project root)
sqlc generate

### Query File Format
-- name: FunctionName :one   # returns single row
-- name: FunctionName :many  # returns multiple rows
-- name: FunctionName :exec  # returns nothing
SELECT * FROM users WHERE name = $1;

### Config (sqlc.yaml)
version: "2"
sql:
  - schema: "sql/schema"
    queries: "sql/queries"
    engine: "postgresql"
    gen:
      go:
        out: "internal/database"
